the idea is to focus more on thinking and not on hoarding 
move from being a "collector" to "retreiver"

a. pattern.md – one page, hand-written summary you close the file and re-type from memory once a day.
b. template.java / template.py – skeleton code with blanks (___) you fill without looking.
c. driver.java / driver.py – three problems only (Easy → Med → Med+) with driver code that prints pass/fail.
