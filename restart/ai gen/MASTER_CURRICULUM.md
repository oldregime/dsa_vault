## 🚀 The "Retriever" Study Protocol
1. **Identify Pattern:** Before coding, match the problem to a sub-pattern above.
2. **Skeleton First:** Write the base loop from memory (use `TWO_POINTER_SKELETONS.md` etc).
3. **20-Min Struggle:** No hints or solutions for the first 20 minutes.
4. **Visual Debug:** Use [Python Tutor](https://pythontutor.com/) to watch pointer movement.
